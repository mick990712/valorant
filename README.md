# 激情四射

單人對抗電腦的 3D 第一人稱戰術射擊原型。

## 操作方式

- WASD：移動
- 滑鼠：轉動視角與瞄準
- 滑鼠左鍵點擊：單發
- 按住滑鼠左鍵：連發
- R：重新裝填
- Esc：暫停或解除滑鼠鎖定

子彈會沿準心方向飛行，並可被掩體阻擋；敵人也會發射可見子彈。
每回合有 90 秒。擊敗全部 3 名敵人即可獲勝；生命值歸零或時間結束則回合失敗。

## 執行

本遊戲使用瀏覽器 ES modules，需透過本機 HTTP 伺服器開啟。若已安裝 Python，在專案資料夾執行：

```powershell
python -m http.server 8000
```

接著用瀏覽器開啟 `http://localhost:8000`。Three.js 由 jsDelivr 載入，因此首次開啟需要網路連線。
